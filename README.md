# 💰 ex015 - Objetos (Banco JS)

Exercício simples de lógica em JavaScript utilizando objetos para simular uma conta bancária.

## Funcionalidades

- Depósito com validação
- Saque com verificação de saldo
- Exibição de mensagens com saldo anterior, valor e saldo atualizado

## Tecnologias

- JavaScript puro
